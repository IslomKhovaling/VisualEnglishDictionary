# Visual English Dictionary — Android

Самостоятельный Android-проект на Kotlin, Jetpack Compose и DataStore. Не связан с Lumo.

## Словарная база
В `app/src/main/assets/words.json` добавлено **3 015 словарных записей**, извлечённых из тематических страниц 11–278 загруженного PDF. Для каждой записи сохранены тема, английское слово/словосочетание, транскрипция, русская фонетическая подсказка, перевод и назначенная иллюстрация. Если в исходной странице удалось извлечь не все поля, некоторые поля могут быть неполными.

14 тематических разделов:
Дом, Люди, Здоровье, Работа, Обучение, Покупки, Пища, Общественное питание, Службы, Транспорт, Досуг, Спорт, Окружающая среда, Флора и фауна.

**Важно:** издательство указывает около 4 500 слов и словосочетаний. Текущая автоматическая выгрузка содержит 3 015 записей, а не весь объём книги. PDF имеет сложную многоколоночную верстку; некоторые записи могут требовать ручной проверки. В `dictionary_audit.json` сохранена статистика извлечения. Для публичного распространения нужно проверить права на использование базы.

## Функции приложения
- офлайн-поиск по английскому и русскому тексту;
- тематические разделы и иллюстрированные карточки слов;
- IPA и русская подсказка произношения;
- системное озвучивание через Android Text-to-Speech;
- избранное с сохранением после перезапуска;
- карточки для запоминания;
- тест из 10 вопросов с вариантами ответа и подсчётом результата;
- тёмная тема и настройка размера текста;
- статистика обучения.

## Иллюстрации
В проект включены 16 новых сгенерированных иллюстраций. Они используются повторно для тематически близких слов. Оригинальные изображения издательства не копировались.

## Сборка
Открыть папку проекта в Android Studio (JDK 17, Android SDK 35), дождаться Gradle Sync и выполнить Build > Build APK(s). APK в этой среде не собирался и не тестировался.
